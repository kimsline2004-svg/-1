# 국채금리 수익률 계산기

미국 10년 국채금리를 입력하면, **과거 같은 금리대에서 시작한 달들이 그 뒤 1년·3년·5년
동안 실제로 낸 수익률**을 보여주는 정적 웹앱입니다. 자산은 **S&P 500 주식**과
**10년 국채** 중에 고르고, 1950년대 이후 · 1980년대 이후 · 2010년대 이후 세 기준을
나란히 놓습니다.

```
app/        브라우저에서 바로 열리는 앱 (HTML + CSS + JS, 라이브러리 없음)
pipeline/   원본 데이터와 통계 생성 스크립트
dist/       한 파일로 합친 배포본
docs/       방법론 상세
```

## 실행

```bash
python3 -m http.server 8000 --directory ust10y/app   # http://localhost:8000
```

또는 `dist/ust10y-calculator.html` 한 파일을 브라우저로 바로 열어도 됩니다
(데이터가 파일 안에 들어 있습니다).

## 데이터 다시 만들기

```bash
python3 ust10y/pipeline/build_dataset.py     # app/data/ust10y_panel.json 생성
python3 ust10y/pipeline/build_artifact.py    # dist/*.html 생성
```

표준 라이브러리만 씁니다. 원본 CSV는 `pipeline/data/`에 함께 커밋되어 있습니다.

| 파일 | 내용 | 출처 |
|---|---|---|
| `ust10y_monthly.csv` | 미국 10년 국채금리 월평균 1953–2026 (FRED `GS10`) | [datasets/bond-yields-us-10y](https://github.com/datasets/bond-yields-us-10y) |
| `sp500_monthly.csv` | S&P 500 월평균 지수와 주당 배당 1953–2026 (Shiller) | [datasets/s-and-p-500](https://github.com/datasets/s-and-p-500) |
| `cpi_us_monthly.csv` | 미국 CPI-U 월별 1913–2026 | [datasets/cpi-us](https://github.com/datasets/cpi-us) |

## 수익률의 뜻

**10년 국채** — 금리는 수익률이 아닙니다. 그래서 10년 만기를 계속 유지하는 국채
포트폴리오의 총수익률(이자 수입 + 가격 변동)을 계산했습니다. 매달 액면가로 발행된
10년 국채를 사고, 한 달 뒤 잔존만기 9년 11개월이 된 그 채권을 그날의 금리로 평가해
판 다음, 다시 새 10년 국채를 삽니다.

**S&P 500** — 지수를 사서 배당을 재투자합니다(가격 + 배당). Shiller의 월별 지수와
배당을 쓰며, 금리와 똑같이 월평균 기준입니다. 배당은 원본이 2023-06에서 끊겨 있어
이후 37개월은 직전 10년 성장률(연 7.5%)로 이어붙였습니다.

1·3·5년 수치는 모두 **연평균(연환산)**입니다. 이렇게 만든 장기 수익률은 1953년 4월
이후 주식 연 11.3%, 국채 연 5.3%로 널리 알려진 값과 맞습니다. 연도별 검증표는
[docs/METHODOLOGY.md](docs/METHODOLOGY.md)에 있습니다.

## 반드시 알아둘 한계

- **주식은 이 방법의 설명력이 거의 없습니다.** 상관계수가 0 부근입니다. 주식 화면은
  "금리가 X%일 때 주식이 얼마를 냈다"는 기록이지 예측이 아닙니다.
- **관측치가 겹칩니다.** 이웃한 두 달의 5년 수익률은 59개월을 공유합니다. 표본
  100개월은 독립적인 사건 100건이 아니라 8년 남짓의 기록입니다. "플러스 확률 100%"도
  100번의 독립 시행이 아닙니다.
- **기준 기간마다 있었던 금리대가 다릅니다.** 2010년 이후에는 8% 금리가 한 번도
  없었고, 1953~79년에는 2% 미만이 거의 없었습니다. 표본 없음이 정상입니다.
- **국면이 다릅니다.** 1953~81년은 금리 상승기, 1982~2020년은 40년 하락기였습니다.
  같은 5%라도 어느 국면의 5%였는지에 따라 이후 결과가 갈립니다.
- **명목에는 물가가 빠져 있습니다.** 10% 이상에서 시작한 5년 수익률은 국채가
  명목 +15.0% / 실질 +10.6%, 주식이 명목 +18.0% / 실질 +13.4%입니다. 앱에서 실질
  기준으로 바꿔 볼 수 있습니다.
- **미래를 보장하지 않습니다.** 교육·연구용이며 투자 자문이 아닙니다.
