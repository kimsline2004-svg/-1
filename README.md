## 공포탐욕 수익률 계산기

CNN Fear &amp; Greed Index 점수를 입력하면, **1980년 이후 같은 점수대에서 실제로 나온
S&amp;P 500의 이후 1년 수익률 분포**를 보여주는 정적 웹앱입니다.

```
app/        브라우저에서 바로 열리는 앱 (HTML + CSS + JS, 라이브러리 없음)
pipeline/   원본 데이터와 통계 생성 스크립트
dist/       한 파일로 합친 배포본
docs/       방법론 상세
```

### 실행

```bash
python3 -m http.server 8000 --directory app   # http://localhost:8000
```

또는 `dist/fng-calculator.html` 한 파일을 브라우저로 바로 열어도 됩니다
(데이터가 파일 안에 들어 있습니다).

### 데이터 다시 만들기

```bash
pip install pandas numpy
python3 pipeline/build_dataset.py     # app/data/fng_stats.json 생성
python3 pipeline/build_artifact.py    # dist/*.html 생성
```

원본 CSV는 `pipeline/data/`에 함께 커밋되어 있어 네트워크 없이도 재현됩니다.
최신 데이터로 갱신하려면 아래 출처에서 같은 이름으로 내려받아 덮어쓰면 됩니다.

| 파일 | 내용 | 출처 |
|---|---|---|
| `cnn_fng.csv` | CNN 공포탐욕지수 일별 2011–2026 | [whit3rabbit/fear-greed-data](https://github.com/whit3rabbit/fear-greed-data) |
| `sp500_daily.csv` | S&amp;P 500 일별 1927–2019 | [fja05680/dow-sp500-100-years](https://github.com/fja05680/dow-sp500-100-years) |
| `spy_daily.csv` | SPY 일별 2000–2026 (최근 구간 이어붙임) | [willhjw/big_movers](https://github.com/willhjw/big_movers) |
| `shiller_monthly.csv` | S&amp;P 500 월별 + 배당, Shiller/FRED | [datasets/s-and-p-500](https://github.com/datasets/s-and-p-500) |
| `vix_daily.csv` | VIX 일별 1990–2026 | [datasets/finance-vix](https://github.com/datasets/finance-vix) |

### 만드는 방법 요약

1. **지수** — CNN 공포탐욕지수는 2011년에 시작했습니다. 그래서 2011-01-03 이후는
   CNN이 발표한 값을 그대로 쓰고, 그 이전은 CNN의 7개 구성요소 중 가격·변동성으로
   복원 가능한 5개(50일·125일 이동평균 대비 위치, 52주 고점 대비 낙폭, 20일 등락률,
   VIX의 50일 평균 대비 수준)를 직전 3년 분포의 백분위로 바꿔 가중평균한 뒤
   CNN 지수 분포에 맞춰 보정했습니다. 겹치는 2011–2026년 구간에서
   **상관계수 0.83(스피어만 0.82)**입니다.
2. **수익률** — 매 거래일이 하나의 관측치이며, 정확히 1년 뒤(달력 기준) 종가와 비교합니다.
   3개월·6개월·3년(연평균), 가격/배당 포함을 모두 계산합니다.
3. **집계** — 점수 한 칸(0~100)마다 ±5점 이웃을 가우시안 가중치로 묶어
   평균·중앙값·분위수·상승 확률을 냅니다.

자세한 내용은 [docs/METHODOLOGY.md](docs/METHODOLOGY.md)를 보세요.

### 결과 (1980–2025, 1년 후 가격 수익률)

| CNN 단계 | 표본 | 평균 | 중앙값 | 상승 확률 | 최악 | 최고 |
|---|---|---|---|---|---|---|
| 극단적 공포 (0–24) | 1,777일 | +10.4% | +13.1% | 72% | −48.8% | +74.7% |
| 공포 (25–44) | 3,128일 | +9.5% | +11.2% | 75% | −46.3% | +54.5% |
| 중립 (45–55) | 1,945일 | +9.8% | +10.9% | 77% | −44.7% | +46.6% |
| 탐욕 (56–74) | 3,221일 | +11.0% | +12.1% | 82% | −41.0% | +45.3% |
| 극단적 탐욕 (75–100) | 1,428일 | +13.6% | +14.4% | 88% | −42.2% | +39.8% |
| **전체 평균** | 11,499일 | **+10.6%** | +12.2% | 79% | −48.8% | +74.7% |

1년이라는 기간만 놓고 보면 "공포일 때 사라"는 통념과 달리 **탐욕 구간의 평균이 더
높았습니다.** 12개월 모멘텀이 살아 있는 국면이 탐욕 구간이기 때문입니다. 대신 공포
구간은 분포의 꼬리가 훨씬 넓습니다 — 최고 +74.7%와 최악 −48.8%가 모두 공포 구간에서
나왔습니다. 2011년 이후 CNN 실측 데이터만 보면 극단적 공포의 평균이 +13.0%로 올라가는데,
이 기간이 거의 전부 강세장이었기 때문입니다.

### 반드시 알아둘 한계

- **관측치가 겹칩니다.** 매일 계산한 1년 수익률은 서로 364일을 공유합니다.
  표본 11,499개는 독립적인 사건 45건이 아니라 45년치일 뿐입니다.
- **극단 구간은 표본이 얇습니다.** 90점 이상은 45년을 통틀어 194거래일(0.8년치)입니다.
- **2011년 이전은 복원값입니다.** 상관계수 0.83은 높지만 같은 지수는 아닙니다.
- **미래를 보장하지 않습니다.** 분석 기간 대부분이 강세장이라 어느 구간이든 평균은
  플러스로 나옵니다. 교육·연구용이며 투자 자문이 아닙니다.
